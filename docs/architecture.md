# 架构

Deskflow DDC 使用 Vue 3、TypeScript 和 Electron。显示器输入通过 DDC/CI 控制，键鼠与剪贴板传输由独立安装的 Deskflow 负责。

## 模块

| 目录                 | 职责                                                   |
| -------------------- | ------------------------------------------------------ |
| `src/components/`    | 工作台、设备配对、显示器映射、共享设置和活动记录       |
| `src/composables/`   | 桌面状态订阅与配置编辑草稿                             |
| `src/shared/`        | 状态类型和应用动作校验                                 |
| `electron/core/`     | 配对认证、控制协议、切换协调、引擎生命周期、配置与日志 |
| `electron/platform/` | 系统显示器、鼠标定位、全局快捷键和托盘适配             |
| `native/`            | macOS 快捷键桥、Windows 原生 API 桥和原生测试          |
| `resources/vendor/`  | 第三方原生后端源码与许可                               |
| `tests/`             | 协议、状态竞争、进程生命周期与模拟硬件集成测试         |

## 连接与切换

用户选择实体键鼠所在的电脑作为提供端，另一台作为接收端。两端通过配对码认证，使用每次连接生成的随机 nonce 派生双向 AES-256-GCM 密钥，并验证消息序号。连接交换设备身份与 Deskflow TLS 证书指纹，生成隔离的引擎设置。

提供端协调键鼠和画面切换。`activeDeviceId` 表示已观察到的键鼠控制设备；`displayDeviceId` 表示最后完成的显示器指令目标，不能作为物理画面的实时读值。DDC 通过最后的画面指令目标对应的电脑发送，不根据当前键鼠归属猜测发送端。

`displayStatus` 区分尚无指令、已发送和不确定。DDC 失败或超时后保留最后已知目标并暂停自动切屏，等待用户手动确认画面并重新连接。

独立屏幕模式允许键鼠归属和共用显示器输入不同。Deskflow 提供原生屏幕边缘切换，PointerBridge 处理独立屏幕出口和鼠标落点。Vue 界面不处理系统输入事件。

## 平台适配

macOS 使用 m1ddc 控制 Apple Silicon 兼容连接，Swift 桥处理权限检查、切换键和鼠标落点。Windows 使用私有 stdin/stdout JSON 行协议复用 PowerShell 辅助进程，由 C# 绑定 DXVA2 和 User32；无网络监听，固定动作集合，请求串行且超时后不重放。

引擎停止会先请求终止，再升级为强制终止，并等待退出确认。未确认退出时保留进程引用，阻止重复启动。Windows 私有 Deskflow 目录按文件元数据缓存更新，并保留隔离的设置和信任库。

## 状态与持久化

内部控制通知立即发送，界面快照按 250ms 合并。配置保存串行执行，使用唯一临时文件和原子替换。编辑草稿按字段合并外部更新，初始快照不会覆盖已收到的推送。

配对密钥在系统能力可用时通过 Electron safeStorage 加密。日志限制文件大小和数量、过滤敏感字段，不记录输入事件或剪贴板内容。旧版配置目录与协议标识保留兼容，产品名称不作为网络身份依据。
