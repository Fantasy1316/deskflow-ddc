# Tauri 2 Preview 迁移与验收

## 隔离与回退

- 稳定基线：`v0.1.11`；迁移分支：`upgrade/tauri-v0.2`。
- Preview 产品名：`Deskflow DDC Preview`；应用标识：`app.deskflow-ddc.preview`。
- 配置、系统凭据、引擎证书、日志均使用独立目录/服务，不自动读取或写入稳定版数据。
- 默认控制端口 `49729`、Deskflow 端口 `24801`。开始 Preview 共享前需先停止稳定版共享，不接管其他 Deskflow 引擎。
- 回退时退出 Preview，重新打开稳定版；稳定版配置无需迁回。

## 已迁移的边界

- Vue 保留原界面和草稿保护；通过 Tauri 命令和带修订号的事件接入 Rust。
- Rust 管理配置原子写入、系统凭据、加密控制协议、设备指纹、RPC、重连、日志和子进程生命周期。
- Deskflow 作为独立子进程内置，固定 1.27.0，保留 TLS 指纹校验与独立配置。macOS 使用稳定的私有临时目录；Windows 保留完整运行库，避免每次启动复制运行时。
- 运行库压缩随包分发，首次校验并解压到 Preview 私有缓存；保留框架链接，后续启动复用，不依赖用户另行安装 Deskflow。
- 保留键鼠归属与画面归属分离；DDC 失败后将画面标为不确定，后续切换不得回退到键鼠归属猜测发送端。
- 主机名解析、mDNS 服务发现、手动备用 IP 和上次已认证地址按顺序尝试。每次重新连接都重新解析并校验身份；发现结果不视作信任关系。
- 用户主动选择旧设置文件时仅导入配置；不尝试直接解密 Electron safeStorage。导入后重新配对。

## 验收场景

自动测试验证协议、帧认证/防重放、双向 RPC 与超时取消、身份绑定、备用地址去重、配置写入/只读导入、鼠标几何和视频切换策略、拥有进程的强制退出。

仍须在实际的两台电脑和显示器上逐项验证，不能用单元测试或打包成功替代：

- [ ] Mac 提供 / Windows 接收，双向按钮和快捷键切换。
- [ ] Windows 提供 / Mac 接收；两台 Windows 同样按提供/接收角色配置。
- [ ] 内置 Deskflow 的辅助功能、输入监控与 Windows 防火墙授权。
- [ ] 选择独立屏幕，四个布局方向、负坐标和不同 DPI 的鼠标落点。
- [ ] 外接屏显示 Windows 时，Mac 内置屏与 Windows 之间只转移键鼠，不误切画面。
- [ ] 共享屏幕不可见的外侧边缘不得触发误切换。
- [ ] DDC 写入失败/超时后停止自动切屏，键鼠恢复结果与日志一致。
- [ ] 主机 IP 变化后，mDNS/主机名获取新地址；禁用组播后验证手动 IP 兜底。
- [ ] 断网、重连、睡眠恢复、对端退出，不遗留引擎或占用端口。
- [ ] 停止/退出与正在识别、启动、切屏同时发生时，旧会话不再更新新会话。
- [ ] 未安装独立 Deskflow 的新机器能够启动内置引擎；离线启动不触发下载。
- [ ] 配对凭据不可用时明确报错，不静默更换身份或覆盖旧版。

公开发行前，还需在真实 Windows 机器完成构建和验收，检查签名、公证及随包第三方运行库许可材料。当前 Preview 不等同于已经完成双机验证的正式版本。

## 本地验证记录（2026-10-27）

验证环境为 Apple Silicon、macOS 15.5；应用及本机原生桥的最低系统版本均为 14.0。

| 检查                                            | 结果                                                                     |
| ----------------------------------------------- | ------------------------------------------------------------------------ |
| TypeScript / Vue 类型检查和前端生产构建         | 通过                                                                     |
| Vitest 回归测试                                 | 22 个文件，147 项通过（含保留的 Electron 行为回归）                      |
| Rust 完整测试（含桌面命令边界）                 | 30 项通过                                                                |
| 实际官方引擎运行库测试                          | 独立测试目录解压、macOS 深度签名校验、执行 1.27.0 版本查询、缓存复用通过 |
| 原生 DDC 响应解析检查                           | 通过；未发送真实输入源写入                                               |
| Rust 优化构建 / Tauri 应用打包                  | 通过                                                                     |
| Preview 本地应用整体签名完整性                  | 通过；为 ad-hoc 签名，不是发行公证                                       |
| Preview 窗口实际启动                            | 已打开，读取独立配置并显示内置引擎就绪                                   |
| Windows 原生构建、双机共享、DDC、变更 IP 后重连 | 待实机验收；CI 工作流已准备但未运行                                      |

准备 Mac 运行库时禁用 BSD tar 的 AppleDouble 元数据输出，避免 Rust 解压产生额外 `._*` 文件而破坏 Qt 框架的资源签名。实际运行库测试同时检查深度签名和可执行性，覆盖该打包故障。主应用通过 Tauri 完成本地包签名，避免仅依赖裸 Rust 二进制的链接器签名。
