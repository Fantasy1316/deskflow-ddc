Deskflow DDC 将键鼠控制和显示器输入切换协调起来，适合两台电脑共用一块显示器的桌面环境。键盘鼠标可以连接在任意一端，不绑定操作系统。

这是独立项目，与 [Deskflow](https://github.com/deskflow/deskflow) 官方无隶属关系。Deskflow 需要单独安装。

## 功能

- **画面与键鼠同步切换**：使用快捷键、应用按钮或屏幕边缘，在两台电脑之间切换。
- **可配置的屏幕布局**：拖动电脑图块，选择左、右、上、下方的跨屏方向。
- **独立屏幕模式**：目标电脑另有内置屏或外接屏时，可以只转移键鼠，让共用显示器保持当前画面。
- **剪贴板共享**：由 Deskflow 提供，可开关并设置容量上限；图片和富文本的兼容性取决于 Deskflow 与两端系统，文件传输和文件拖拽未提供。
- **局域网配对**：配对码认证、加密控制连接，并校验 Deskflow 的设备证书指纹。
- **诊断日志**：导出两端日志，帮助定位连接、权限和显示器控制问题。

## 使用条件

| 项目     | 要求                                                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------------------- |
| macOS    | Apple Silicon Mac；暂不支持 Intel Mac 的 DDC 控制                                                                 |
| Windows  | Windows x64                                                                                                       |
| 显示器   | 支持 DDC/CI，且支持通过 VCP `0x60` 修改输入源                                                                     |
| 连接     | 两台电脑分别接入同一块显示器的不同输入接口                                                                        |
| 网络     | 两台电脑位于可互通的局域网                                                                                        |
| 键鼠引擎 | 两端分别安装 [Deskflow 1.27.0](https://github.com/deskflow/deskflow/releases/tag/v1.27.0)；其他版本兼容性尚未确认 |

扩展坞、转接器和线材可能影响 DDC/CI。显示器支持输入源切换，不代表每一种连接方式都能通过软件控制；建议先确认两端均能单独发送切换指令。

## 安装

1. 在两台电脑上分别安装 Deskflow 和 Deskflow DDC。应用构建方法见 [从源码构建](docs/build.md)。
2. macOS 打开 `Deskflow DDC.app`；Windows 运行 `Deskflow DDC.exe`。若使用目录分发版本，需保留旁边的 DLL 与 `resources`，不要在 ZIP 内直接运行。
3. 开始共享前，退出独立运行的 Deskflow，包括托盘与后台服务，避免端口或引擎冲突。Deskflow DDC 会启动使用独立配置的 `deskflow-core`。
4. macOS 按系统提示为相关进程开启辅助功能或输入监控权限。应用中的权限检查不能代替 Deskflow 自身的权限检查。

## 快速开始

### 1. 配置显示器

两端分别进入 **显示器与输入**，扫描并选择共用显示器，填写本机与另一台电脑对应的输入源数值，保存设置。

两端需要反向填写。例如，电脑 A 的接口实测值为 `3`、电脑 B 为 `1`：

| 电脑 | 本机输入源 | 另一台输入源 |
| ---- | ---------- | ------------ |
| A    | 3          | 1            |
| B    | 1          | 3            |

以上只是示例。**请使用实际验证过的数值**，不要仅凭 HDMI、DVI 或 VGA 的接口名称推断。两端显示器设备 ID 可以不同，需各自扫描选择。

停止共享后，可以使用“单独测试显示器切换”验证映射。测试会立即改变画面；若切到另一台后无法返回，请使用显示器实体按键恢复。

### 2. 选择键鼠角色

进入 **设备与配对**：

- 实体键鼠所在的电脑选择 **连接在这台电脑**，作为提供端。
- 另一台选择 **连接在另一台电脑**，作为接收端。

两台 Windows、两台 Mac 或 Windows / Mac 混合均使用相同规则。

### 3. 配对并连接

1. 先让共用显示器显示键鼠提供端的画面。
2. 提供端点击 **开始等待连接**。
3. 接收端填写提供端的局域网地址和配对码，保存地址后点击 **配对并开始共享**。
4. 工作台显示共享已连接后，尝试切换。

默认控制端口为 TCP `49728`，键鼠端口为 TCP `24800`。两端配置应一致，并允许相应的局域网连接。

默认切换快捷键：

| 键鼠提供端 | 快捷键                |
| ---------- | --------------------- |
| macOS      | `Ctrl + Option + F12` |
| Windows    | `Ctrl + Alt + F10`    |

macOS 可能需要同时按 `Fn`，取决于功能键设置。Windows 的 `F12` 是系统保留键，请选择其他功能键。停止共享后可在 **共享设置** 修改快捷键。

### 4. 设置鼠标跨屏

停止共享，在提供端进入 **共享设置 → 屏幕布局与鼠标跨屏**，拖动电脑图块设置方向。接收端连接后使用提供端的布局。

- **跟随键鼠切换画面**：适合只有一块共用显示器的场景，越过指定边缘时同时切换画面和键鼠。
- **目标有独立屏幕时仅转移键鼠，否则切换画面**：两端各自选择本机独立屏幕。进入有独立屏幕的电脑时，共用显示器保持原输入，鼠标落在所选屏幕上。

独立屏幕不能选择共用显示器。按钮和切换快捷键始终用于切换共用显示器画面。

## 常见问题

**连接一直停留在“引擎连接中”**

确认两端 Deskflow 版本、局域网地址和端口一致，退出独立 Deskflow 实例，检查防火墙与 macOS 权限。配对成功只表示控制连接建立，不代表键鼠引擎已经就绪。

**扫描不到显示器，或输入源写入失败**

检查显示器 DDC/CI 开关、当前输入源、线材及扩展坞。部分连接只能在当前活动输入下发送 DDC。控制程序报告“指令已发送”不等于物理画面已经成功显示。

**提示“外接屏输入状态不确定”**

输入源写入失败或超时后，应用会暂停自动切屏，避免通过错误的电脑发送后续指令。请停止共享，使用显示器按键将画面切到键鼠提供端，再重新连接。

**切换后画面与键鼠不一致**

`Ctrl + Alt + Esc` 可请求返回键鼠提供端；独立屏幕模式会按所选跨屏规则处理画面。停止共享、断线或退出不会保证自动恢复显示器输入，必要时使用显示器实体按键。

**局域网 IP 变化后无法连接**

当前按配置的地址连接，尚未实现设备自动发现。可在路由器设置 DHCP 地址保留，或更新接收端保存的提供端地址。

**如何报告问题**

在两端分别打开 **活动记录 → 导出诊断日志**，提供系统、应用和 Deskflow 版本、接线方式及复现步骤。日志包含设备名、局域网地址、配置摘要及错误信息；分享前请检查其中的信息。不要提交配对码、证书私钥或完整配置文件。

## 隐私与限制

- 控制连接在局域网内直接建立；键鼠与剪贴板由 Deskflow 传输。
- 配对密钥在可用时由 Electron `safeStorage` 加密；证书私钥保存在本机。
- 本应用不记录按键、鼠标轨迹或剪贴板内容。诊断日志会过滤配对码和私钥。
- 当前为一对一共享；不提供远程桌面视频、USB 转发、自动唤醒或文件传输。
- UAC 安全桌面、锁屏、睡眠等场景存在限制，请保留本机操作或恢复手段。
- 显示器、扩展坞和操作系统组合差异较大，首次使用请先验证双向切换与手动恢复。
